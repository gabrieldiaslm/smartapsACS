# Smart APS - Controle Vacinal

Sistema web desenvolvido para auxiliar **Agentes Comunitários de Saúde (ACS)** no monitoramento e registro do calendário vacinal de crianças. O objetivo é simplificar a identificação de atrasos vacinais e facilitar o trabalho de campo.

---

## Funcionalidades Principais

* **Cadastro de Crianças:** Registro completo com dados do SUS (CNS), mãe e localidade.
* **Censo Demográfico Inteligente:**
    * Visão geral da área com estatísticas (Total, Meninos, Meninas, Bebês).
    * **Alerta Automático:** Identifica crianças com vacinas atrasadas ou em dia.
    * Filtros por Status, Sexo e Ordenação por idade.
* **Cartão de Vacina Digital:**
    * Linha do tempo visual das vacinas.
* **Registro de Aplicação:**
    * Formulário seguro com preenchimento automático de data.
    * Seleção do profissional (ACS) responsável pela aplicação (parceiros da equipe).
    * Controle de Lote e Fabricante.
